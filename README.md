A whole love story in 30 characters, entered for the make.fun bounty
"Tell a Whole Story in 32 Characters" (prize: 2 USDC).

## The story

```
ProposedOverHotspot_SheSaidYes
```

He proposed over the coffee-shop Wi-Fi hotspot — and she said yes.
A proposal, a place, and a happy ending, all inside the 32-character limit.

## How it works

`main.py` embeds the entry, validates it against the contest gate
(1–32 characters, not only whitespace, single line), and writes it with
no trailing newline to `entry.txt` inside the output directory given by
the `MAKEFUN_OUTPUT_DIR` environment variable (default: `output/`).

## Run

```
python3 main.py
```
